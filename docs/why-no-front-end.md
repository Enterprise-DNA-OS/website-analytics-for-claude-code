# Why there is no front end

The weekly job is to reconcile visit history, compare acquisition and landing pages, assign improvements and prepare a brief. Those jobs work through database queries and the command recipes. Read-only HTML gives the owner a printable view of the results. The coding agent performs the work in the repository.

A full analytics application also gives visual exploration, interactive filters, administration screens, browser tracking, consent controls, mobile access and session replay. This base does not provide those. It is a saved-history review system, with no automatic collection and no real-time dashboard. Matomo Community is already free and self-hosted; choose it when its wider platform fits.

Enterprise DNA can connect collection, add a screen, change measurement rules or operate the system as part of a custom version. Scope and reconcile those functions before replacing a working analytics service.

Run npm run view for the private dashboard and npm run docs for the website and privacy review paperwork. Set brand.json once. /new-view adds a report, and /customise adds a field or rule through a tested migration. No public hosting is required.
